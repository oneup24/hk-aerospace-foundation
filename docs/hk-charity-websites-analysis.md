# 香港五大慈善基金會網站分析報告

**研究日期：** 2026-09-29
**研究員：** Kilo
**研究對象：** 5 個香港具代表性的慈善基金會網站

---

## 研究目的

透過分析香港五大慈善基金會的官方網站，歸納其內容架構、導航設計、視覺風格及功能特色，作為日後籌建本地航天基金會（HK Aerospace Foundation）網站時的設計參考。

---

## 一、香港公益金 (The Community Chest of Hong Kong)

**網址：** https://www.commchest.org

### 1.1 機構背景
香港公益金成立於 1968 年，是香港歷史最悠久、規模最大的慈善籌款機構之一，旗下資助超過 165 間社會福利會員機構，每年受惠人次超過 350 萬。

### 1.2 網站內容架構
主要分為六大主欄目：

| 主欄目 | 子內容 |
|---|---|
| **關於我們** | 使命與角色、我們的故事、公益里程、架構、聯絡我們、常見問題 |
| **捐款與支持** | 籌募活動、最新活動、捐款方法（網上/每月/其他）、企業義工配對計劃 |
| **撥款與資助** | 撥款策略及程序、本年度撥款、會員機構、資助服務、服務透視 |
| **及時雨基金** | 基金簡介、批核中心、受助個案、醫療援助基金、系統登入 |
| **新聞中心** | 新聞稿、年報、籌募年報、公益金通訊、影音廊 |
| **教育** | 學校講座、學習資源 |

### 1.3 設計風格
- **色調：** 以白色為主，配以品牌紅色作點綴
- **頂部導航：** 傳統水平下拉式選單，附帶 A 字大小切換（無障礙功能）
- **首頁焦點：** 大幅橫幅輪播（Banner Carousel）展示籌款活動（聖誕、賣旗日、綠色低碳日等）
- **互動元素：** 「撥款與資助 / 會員機構 / 服務透視 / 最高籌款機構」四標籤切換卡片
- **數據展示：** 大型數字動態呈現（$277M+ 撥款總額 / 166 會員機構 / 305 受資助服務計劃）
- **無障礙：** 榮獲「數碼無障礙嘉許計劃 2024-2025 網頁金獎」
- **多語言：** 繁體中文 / 英文
- **社群連結：** Facebook、Instagram、YouTube
- **訂閱功能：** 頁腳提供電子報訂閱（需確認私隱政策）

## 二、樂施會 (Oxfam Hong Kong)

**網址：** https://www.oxfam.org.hk

### 2.1 機構背景
樂施會於 1976 年在香港成立，是國際樂施會聯會成員之一，於 2026 年迎來 50 週年。扶貧工作遍及全球 23 個國家及地區，服務對象包括香港、中國內地、亞洲、非洲及中東等。

### 2.2 網站內容架構
內容層級較深，採國際化多語言結構（繁體 / 簡體 / 英文）：

| 主欄目 | 子內容 |
|---|---|
| **關於樂施會** | 願景使命、管治架構、總裁的話、獎項聯盟、歷史、年報、公眾捐款的運用 |
| **扶貧工作** | 發展項目（港/中/澳/台/海外）、人道救援（中/亞/非/中東/其他）、倡議工作 |
| **50 周年** | 周年慶典專區 |
| **你的參與** | 籌款活動（毅行者、米義賣、音樂馬拉松、競跑旅遊塔）、學校及公眾教育、樂施之友、扶貧企業夥伴、實習生 / 義工、樂施商店 |
| **最新消息 / 專題故事 / 捐款支持** | 包含每月捐款、一次過捐款、遺產捐贈、企業捐款、籌款者專頁、結婚禮品等 |

### 2.3 設計風格
- **色調：** 以白色及綠色（品牌色）為主，視覺上強調環保與人道關懷
- **首頁焦點：** 多張大型 Key Visual 橫幅輪播（緊急救援、50 周年、毅行者、每月捐款）
- **國際化設計：** 與全球 Oxfam 風格一致，採用攝影強、文件厚重的人文圖片
- **互動組件：** 「Oxfam's Picks」多標籤切換（倡議 / 發展 / 人道救援 / 義工）
- **捐款機制：** 首頁即顯示捐款金額選項（$500 / $1000 / $2000 / 自訂），採用透明化呈現
- **國際連結：** 頁腳提供多國 Oxfam 入口（美/澳/英/法/德/日 等近 20 國）
- **得獎標記：** 頁底標註 W3 Gold Award 及 WebAward Standard of Excellence，強調國際設計水平
- **無障礙：** 提供「無障礙聲明」

## 三、香港紅十字會 (Hong Kong Red Cross)

**網址：** https://www.redcross.org.hk

### 3.1 機構背景
香港紅十字會於 1950 年成立，是國際紅十字及紅新月運動成員之一，總部位於西九龍海庭道 19 號。除人道救援外，香港市民最熟悉的是其輸血服務（自 1952 年起，現由醫管局營運）。

### 3.2 網站內容架構
由於官方網站內容較難直接抓取（重定向至 `/tc/index.html`），但從文獻及維基百科得知其架構：

| 主欄目 | 子內容 |
|---|---|
| **關於本會** | 歷史、贊助人及主要職員、組織架構、義工團隊 |
| **服務總覽** | 輸血服務（轉至醫管局）、醫療服務、特殊教育、社會福利服務、人道救援、青年及義工事務 |
| **急救及健康** | 急救訓練課程、健康講座、醫療器材租借 |
| **災難救援** | 海外及內地救援項目、備災工作 |
| **捐血 / 捐款** | 捐血預約、月捐計劃、遺產捐贈 |
| **紅十字青年** | 制服團隊（中學 / 青年中心 / 長者組別） |
| **新聞中心** | 新聞稿、活動花絮、刊物下載 |

### 3.3 設計風格
- **色調：** 經典紅十字品牌色「紅色 + 白色」，辨識度極高
- **標誌：** 國際通用紅十字標誌，帶來強烈國際人道組織權威感
- **頁面風格：** 較為傳統、官方機構味道濃；以資訊公布及服務申請為主，視覺刺激較少
- **語言：** 繁體中文 / 英文
- **重要標記：** 標示贊助人為香港特別行政區行政長官，強化官方地位

## 四、東華三院 (Tung Wah Group of Hospitals)

**網址：** https://www.tungwah.org.hk

### 4.1 機構背景
東華三院成立於 1870 年，是香港歷史最悠久的慈善機構。提供六大類服務：醫療、教育、社會、籌募、歷史文化保育、公共服務。2025 年正值 155 周年。

### 4.2 網站內容架構

| 主欄目 | 子內容 |
|---|---|
| **關於我們** | 歷史、願景使命信念、企業管治（顧問局/董事局/委員會/行政部門）、旗下服務單位、供應商註冊、招標公告、加入東華 |
| **醫療服務** | 服務簡介、架構、消息及活動、常見問題 |
| **教育服務** | 學校概覽、辦學特色、獎學金及資助、學生輔導、活動典禮、校友專區 |
| **社會服務** | 服務簡介、服務成就、常見問題 |
| **籌募活動** | 「東華之友」月捐計劃、「杏林之友」、「殯儀基金」、捐款辦法、善款運用 |
| **歷史文化保育** | 簡介 |
| **公共服務** | 服務簡介 |
| **社會責任** | 綠色機構、義工、可持續發展 |
| **新聞中心** | 新聞稿、活動預告、殊榮、短片、刊物、周年誌慶網站 |

### 4.3 設計風格
- **色調：** 紅色 + 白色 + 黃金色，帶出傳統中式慈善機構的莊嚴感
- **版面：** 傳統多欄式 WordPress 模板（基於 `tw2015` 主題），於 2026 年看起來略顯過時
- **首頁：** 多張活動橫幅輪播 + 「關於 / 醫療 / 教育 / 社會 / 籌募 / 文化 / 公共 / 綠色」八大分類圖示方塊
- **社群連結：** Facebook、Google+（已停用）、新浪微博、Email、WeChat QR Code
- **多語言：** 繁體中文 / 簡體中文 / 英文
- **無障礙：** 標示「Web Accessibility Recognition Scheme 2016」
- **特色：** 提供 iOS / Android 官方 App 下載；附有 155 周年專屬子網站

## 五、保良局 (Po Leung Kuk)

**網址：** https://www.poleungkuk.org.hk

### 5.1 機構背景
保良局成立於 1878 年，香港六大傳統慈善機構之一。服務範疇包括教育、社會、青少年、康樂（度假營）、文化（博物館）、醫療及綜合健康。每年服務超過 70 萬人次。

### 5.2 網站內容架構
為五個網站中內容最豐富、欄目最細緻者：

| 主欄目 | 子內容 |
|---|---|
| **保良局服務** | 教育服務（基金獎學金）、社會服務（家庭/幼兒/康復/安老/社企）、青少年服務（7 大類）、度假營（北潭涌、大棠）、歷史博物館、醫療及綜合健康 |
| **保良故事集** | 感人故事專欄（長期病患兒童、特殊學員、自閉學員、長者等真實個案） |
| **支持保良** | 網上捐款、贊助計劃、籌款活動、夥伴連繫、社企產品、名人分享、義工服務、遺產捐贈 |
| **新聞及刊物** | 新聞稿、重點報道、今日保良、通訊、年刊、影片 |
| **關於保良局** | 簡介、歷史里程碑、管治機構、社會責任（環保/共融/人才/文化）、招標公告、善款運用 |
| **加入我們** | 職位空缺、員工福利、員工故事、工程公司及供應商登記 |

### 5.3 設計風格
- **色調：** 品牌藍綠色 + 白底，現代化、簡潔
- **頂部導航：** 採 SVG logo、語言切換（繁/簡/英）、社交分享按鈕
- **首頁結構：** 服務分類 icon 切換（6 大服務）+ 大型 Banner 輪播 + 「個人捐款 / 企業捐款」雙入口 + 最新資訊 + 故事集
- **故事集（Storytelling）：** 採用深度故事行銷，以受惠者真實經歷打動捐款者（每篇 500-800 字，附人物照片）
- **數據透明：** 首頁強調「每年服務超過 70 萬人次」、「控制行政支出」
- **無障礙：** 須啟用 JavaScript 才能瀏覽
- **多語言：** 繁體 / 簡體 / 英文

## 七、關鍵洞察與設計建議

### 7.1 共通元素（值得參考）
1. **頂部都有捐款入口** — 五個網站均在 header 顯眼位置放「立即捐款」按鈕
2. **Banner Carousel 為主流** — 首頁橫幅輪播是慈善機構的標準做法
3. **多語言切換** — 繁體中文為主，幾乎都提供英文，少數提供簡體
4. **無障礙意識抬頭** — 樂施會及公益金明確標示無障礙認證
5. **以攝影說故事** — 大幅真實人物照最能打動捐款者

### 7.2 各自強項
- **公益金：** 撥款數據透明化、四標籤切換卡片、無障礙金獎
- **樂施會：** 國際級設計、首頁捐款按鈕顯眼、W3 得獎
- **保良局：** 深度故事行銷（推薦借鏡）、服務分類 icon 切換
- **東華三院：** 歷史感、官方 App
- **香港紅十字會：** 品牌辨識度、國際權威性

### 7.3 對 HK Aerospace Foundation 網站的建議

| 設計維度 | 建議 |
|---|---|
| **色調** | 借鏡公益金 / 保良局簡潔白底，配上航天主題的深藍 + 銀色，避免過多顏色 |
| **首頁 Banner** | 採用高質航天攝影（如火箭升空、衛星、深空）橫幅輪播 |
| **捐款入口** | 學習樂施會做法，在首頁 hero section 內提供預設金額 + 自訂金額按鈕 |
| **數據透明** | 借鏡公益金，以大型數字展示撥款總額、資助項目數、受惠人次 |
| **故事行銷** | 強烈推薦學習保良局「故事集」單元，建立「受惠者故事」專區 |
| **導航結構** | 參考保良局的「服務分類 icon」首頁切換式導航 |
| **無障礙** | 至少符合 WCAG 2.1 AA 標準（保險起見向公益金 / 樂施會水平看齊） |
| **多語言** | 繁中 + 英文為必備（航天議題國際性強，簡中可選） |
| **國際連結** | 樂施會作法值得參考 — 若日後有國際夥伴關係，可建跨國連結清單 |
| **內容欄目** | 建議六大欄目：關於我們、扶貧項目（航天教育/科研資助）、捐款支持、新聞中心、活動報名、教育資源 |
| **品牌定位** | 借鏡樂施會國際級設計，避免東華三院式的「傳統政府機構」味 |

## 八、總結

香港五大慈善基金會網站反映了不同世代與定位的設計哲學：

- **傳統派（東華三院、紅十字會）** 偏資訊導向、官方權威感強
- **現代派（公益金、保良局）** 強調服務導航與捐款轉化率
- **國際派（樂施會）** 走全球品牌一致路線，設計投入最高

對 HK Aerospace Foundation 而言，**保良局的故事行銷 + 公益金的數據透明 + 樂施會的國際級視覺**，將會是最理想的綜合參考藍圖。
